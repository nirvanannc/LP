# WhatsApp Auto-Reply — Setup Guide (Free, no code)

The website's "WhatsApp" buttons now open a warm, pre-filled message in the visitor's
chosen language. To make the clinic reply **instantly & automatically**, set a Greeting
Message inside the free **WhatsApp Business** app on the phone using **9929300003**.

## One-time setup (5 minutes)
1. On the clinic phone, install **WhatsApp Business** (green icon) from Play Store / App Store.
   - If 9929300003 already uses normal WhatsApp, the Business app will offer to migrate it —
     your chats and number stay the same. (Use Business app, not both, on this number.)
2. Open **WhatsApp Business → Settings → Business tools → Greeting message**.
3. Turn **ON** "Send greeting message".
4. Tap **Greeting message** and paste the text below.
5. Set **Recipients → Everyone**. Save.
   - (Greeting message auto-sends when someone messages you for the first time, or after
     14 days of inactivity.)
6. Optional: also set an **Away message** (Business tools → Away message) for after clinic
   hours using the second template below.

## Greeting message (paste this)
```
Namaste 🙏 Thank you for reaching out to Dr. Aditya Soni Clinic.

Aap akele nahi hain — and everything you share here stays 100% confidential.

Our team will reply personally very soon. Meanwhile, feel free to tell us (in English or Hindi):
• Is this for you or a family member?
• What's troubling you most right now?

There's no judgment here. The first step is just a conversation. 💚
```

## Away message (optional, for after hours)
```
Namaste 🙏 We've received your message and it matters to us.

Right now the clinic is closed (we're here Mon–Sat, 10 AM–7 PM), but we'll reply as soon
as we're back. Your message stays completely private.

If this is urgent, please call us on 9929300003, or the free 24×7 national mental-health
helpline: 14416 / 1800-891-4416. You don't have to handle this alone.
```

## Notes
- This is the standard, zero-cost method used by most clinics — no API keys, no approval.
- For a fully automated bot with buttons/menus later, that would need the WhatsApp Business
  API (Twilio or Meta Cloud API) and a dedicated API number. Not needed for the greeting flow.
